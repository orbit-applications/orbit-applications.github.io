What is a Russian manicure?

A meticulous dry manicure using an e-file for ultra-clean cuticles and a seamless grow-out. It takes longer — and lasts longer.

Do you take walk-ins?

Evenings book out fast, so we strongly recommend calling (403) 555-0125 ahead. Daytime walk-ins are sometimes possible.

How far ahead should I book bridal?

At least 4–6 weeks for the trial, so there's time to perfect the set before the day.
